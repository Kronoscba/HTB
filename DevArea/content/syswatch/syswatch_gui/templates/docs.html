Introduction

SysWatch provides server monitoring plugins and a secure web dashboard to view logs, check service status, refresh metrics, and back up or clean logs.

Features

  • Session-authenticated dashboard
  • CPU/Memory, Disk, Network, Log alerts, Service status
  • Per-section refresh to run plugins
  • Service status checks via systemd
  • Backup and cleanup of logs

CLI

  • Start web: syswatch.sh web
  • List plugins: syswatch.sh plugins
  • Run plugin: syswatch.sh plugin <script>
  • Help: syswatch.sh --help

Configuration

  • SYSWATCH_SECRET_KEY
  • SYSWATCH_ADMIN_PASSWORD
  • SYSWATCH_LOG_DIR
  • SYSWATCH_PLUGIN_DIR
  • SYSWATCH_BACKUP_DIR
  • SYSWATCH_DB_PATH
  • SYSWATCH_VERSION
